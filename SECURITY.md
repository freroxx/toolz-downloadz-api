# Security Policy

If you discover an SSRF, auth bypass, secret leakage, or other vulnerability in `toolz-downloadz-api`:

1. **Email**: Send full details and reproduction steps to **frerox.toolz@gmail.com** with subject `[SECURITY] toolz-downloadz-api`.
2. **Do not disclose publicly**: Allow time for investigation and patch deployment before publishing details.
3. **Safe Harbor**: Legitimate research conducted in good faith without accessing private user data or causing service outages is protected.
